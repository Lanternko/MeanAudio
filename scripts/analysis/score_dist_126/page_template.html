TTM 逐曲分數分佈：生成系統與 MusicCaps 真實錄音

MusicCaps 5,131 個共同 prompt，所有音檔先純量增益到 −30 LUFS（lvl30）再評分。來源：p2 115／118 的逐曲分數。ours 有 3 個訓練 seed。2026-10-16。

同一個 prompt：真實 vs 生成

分位數（箱形）

粗線 p25–p75，細線 p5–p95，點是中位數，端點 p1／p99。

統計

dip p＝Hartigan dip test（< 0.05 表示拒絕單峰，標黃）。BC＝Sarle 雙峰係數（> 0.555 是常用的雙峰提示，但偏態大時也會超過，只當參考）。W₁、KS＝與真實錄音分佈的距離。ρ＝同一個 prompt 下與真實錄音分數的 Spearman 相關。

判讀

  • PQ 沒有兩極分佈。十個系統的 PQ 都是單峰、左偏（dip p 全部 > 0.9）。ours CFG3＋neg 平均 7.59 但 sd 只有 0.71，比真實（6.99／1.11）窄很多，整團被推到上端；MusicGen 也一樣窄（0.80）。偏離真實的方式是「被壓縮到高分」，不是「分成兩群」。
  • CE 有兩極分佈，只出現在生成音訊。ours CFG0 三個 seed 都拒絕單峰（dip p 1e-4、5e-6、0.003），低峰在 CE ≈ 3.3、主峰 ≈ 7.0；MusicLDM 也拒絕（0.045）。真實錄音與 ours CFG3＋neg 是單峰。
  • 低峰是哪些 prompt。ours CFG0 CE < 4.5 的 1,013 首，真實錄音在同一批 prompt 上的 CE 也只有 5.01（其餘 6.42），其中 42% 真實錄音也低於 4.5。這批 caption 多出現 water、didgeridoo、scary、noise、sinister、horror、eerie、effects、game、phone、wind、amateur。也就是音效／氛圍／恐怖／業餘錄音類的 prompt。CE 把「不像一首完整音樂」打低分，生成系統在這類 prompt 上做得比真實錄音更「不像音樂」，所以分成兩群。
  • CFG3＋neg 把低峰收掉了。同一個 ckpt 加負向 prompt 後低 CE 比例從 19.7% 降到 5.9%，比真實錄音（15.2%）還少。分佈比真實更集中，W₁ 反而從 0.20 變 0.84，離真實更遠。
  • MEva 幾乎不認 prompt。所有系統的 MEva 分佈都和真實重疊（W₁ ≤ 0.11），但同 prompt 與真實的相關只有 ρ ≈ 0.08–0.11（AES 是 0.24–0.61）。它對「這首在講什麼」不敏感，分數差異大多是逐曲雜訊。
  • CLAP 單峰，只有平移。真實 0.299，ours CFG0 0.195、CFG3＋neg ≈ 0.23，形狀都一樣。
  • MusicCaps 不是均勻的真實音樂分佈。它含不少業餘、現場、音效錄音，所以「接近真實分佈」在這裡的意思是接近 MusicCaps，不代表接近一般發行音樂。
