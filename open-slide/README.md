# MeanAudio Open Slide

This is a minimal Open Slide workspace copied from the reusable skeleton in
`/home/kojiek/karaoke-jp/decks/final-report-open-slide`.

The karaoke-specific report, screenshots, and assets are intentionally not
copied. The MeanAudio deck lives at:

```text
slides/q-conditioning/index.tsx
```

Run it with:

```bash
npm install
npm run dev
```

Build the static deck with:

```bash
npm run build
```
