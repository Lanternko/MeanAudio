# Hidden Workspace Storage

This folder keeps low-priority or historical material out of the project root.

- `legacy/`: former `archive/` contents, including old fix scripts and generated audio from early phases.
- `source-backups/`: scattered `*.bak` and `*.bak2` source snapshots, preserved by original path.
- `generated-output/`: old local `output/` audio samples.
- `wandb-offline/`: old local W&B offline run folders.

Core source code, configs, experiment docs, and reusable scripts should stay in the visible top-level project folders.
