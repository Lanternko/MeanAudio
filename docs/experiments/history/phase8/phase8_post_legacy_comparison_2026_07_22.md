# Phase 8 legacy reproduction and follow-up experiment comparison

Updated: 2026-07-22 (Asia/Taipei)

This document puts the historical Phase 8 checkpoint, the legacy reproduction,
the experiments run after that reproduction, and the previous best checkpoints
in one paper-readable table. Internal phase codes are retained only in the
`Artifact / internal reference` column; they are not used as experiment names.

## Comparison scope

- Benchmark: MusicCaps, all 5,521 prompts and generated audio files.
- Shared generation protocol for the July experiments: one-step MeanFlow,
  CFG 0.5, seed 42, and no text attention mask (`NoMask`).
- `CLAP`, `CE`, `CU`, `PC`, and `PQ` are higher-is-better in this table.
- `q=9` is the preregistered primary evaluation for Q-conditioned July runs;
  `q=6` is shown as a secondary support-set check.
- `Delta vs matched No-Q` uses the July catalog-matched No-Q result, CLAP
  0.1888, as the reference. Historical checkpoints are not fully matched
  controls because the old runners gave the Q tokens different semantics.

### Naming glossary

- **LP-MusicCaps**: captions generated by the LP-MusicCaps captioning pipeline.
- **Static-random caption**: one caption is selected once per audio clip with a
  fixed random seed and remains unchanged throughout training.
- **Lowest-consensus caption**: among the candidate captions for a clip, select
  the one with the lowest average text similarity to the other candidates.
- **MeanSim quality label**: the candidates' mean pairwise text similarity is
  discretized into a quality token (`q=0` to `q=9`).
- **No-Q**: the learned quality-conditioning pathway is disabled; evaluation
  uses the model's null quality token.
- **Aligned Q / shuffled Q**: aligned Q keeps each label with its source row;
  shuffled Q permutes labels only, while preserving rows, captions, audio,
  label counts, and the rest of the training contract.

## Short conclusion

1. The strongest completed July result is the **catalog-matched model without
   quality conditioning** (CLAP 0.1888).
2. The legacy reproduction with effective Q in both stages loses 0.0204 CLAP
   against that matched No-Q control.
3. Introducing aligned Q only in Stage 2 also fails to improve the No-Q model.
   In both the 200k-step retrain and 100k-step residual fine-tune, shuffled Q
   beats aligned Q. The present experiments therefore do **not** support useful
   information in the current MeanSim Q labels.
4. The previous MusicCaps best remains the historical lowest-consensus-caption
   model at 0.1998, but it was trained under the bug-era half-Q behavior and is
   a historical benchmark rather than a fully matched modern-code baseline.

## Excluded result

The legacy reproduction's initial `--no_q` evaluation (CLAP 0.0134) is not in
the comparison table. That checkpoint was trained with Q, and under the fixed
runners the null token `q=10` represents the unconditional path. The 0.0134
result is therefore an invalid evaluation-protocol mismatch, not an experiment
result.
