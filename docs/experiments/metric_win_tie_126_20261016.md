# 評分模型的兩條基本要求：分得出好壞、說得出平手（126）

> **狀態**：2026-10-16 登錄、已排 queue。使用者要求不再詢問、用預設值，所以下面標「待確認」的項目都照預設登錄（m＝0.10 S、通過＝80%、移調／速度／換 SoundFont 算該平手）。
> 實際跑的版本見文末「登錄版（126a／126b）」；與前面草案不同處以文末為準。
> 來源：使用者對 123 結果的回饋（2026-10-16）；123 結果見 `results/midi_realpiece_control_123_results.md`。

## 目標（使用者原話整理）

我們期望評分模型做到兩件事：

1. **差距夠明顯時，分得出好壞。**
2. **完全相同、或差距不重要時，說得出「平手」。**

目前兩件都做不好。例如同一首音樂只改音量，分數就不同（063：−18→0 dB，PQ 與 CLAP 往相反方向移動），這是不能接受的。

這條線的目標是**明確指出評分模型的缺點，以及它在什麼條件下會出錯**。方法是固定所有變量、一次只改一個，找出指標從答對變成答錯的那個點。
被改的變量必須是「明顯有誤」或「明顯無關」的，所以每一個介入都要誇張、可以一聽就判斷。

## 與 123 的差別

| | 123 | 126 |
|---|---|---|
| 素材 | MAESTRO 比賽曲目（真人演奏，但多數人沒聽過） | **耳熟能詳的曲子**：童謠＋古典名曲（待確認曲目） |
| 樂器 | 鋼琴＋換音色（長笛／尼龍吉他／小提琴／pad） | **只用鋼琴**。MIDI 小提琴與真實提琴差太多、聲音斷裂，換音色的結果無法解讀，移除 |
| 主要讀數 | 群體平均：150 段配對 Δ 的 95% CI | **逐對判定**：每一對（原版, 介入版）判成 勝／平／負，報比例 |
| 不該變的介入 | 11 個，單一幅度 | 平手組擴大成主角，每個都有幅度階梯，也套在真實錄音與 TTM 輸出上 |
| 底線 | 12 個，最差是白噪音 SNR 0 | 加入比白噪音更差的刺激：純 0／1 波形、方波、直流、數位靜音 |
| 幅度 | 多數單一幅度 | **每個介入都做幅度階梯**，找出指標開始答對（或開始答錯）的點 |

為什麼改成逐對判定：要求 1 與 2 都是在講「拿兩段音訊給評分模型，它答得對不對」。
群體平均在 150 段上 CI 不跨零，不代表每一對都分得出來；123 的「全部錯音 PQ −0.06」平均顯著，但大概有很多對是答反的。

## 判定規則（待確認）

對每一對（A＝原版, B＝介入版），指標差 Δ＝score(B) − score(A)：

- |Δ| ≤ m → **平**
- Δ < −m → **B 較差**
- Δ > +m → **B 較好**

平手容許量 m 每個指標各一個。預設 m＝0.10 S，S＝表 B 六個系統 lvl30 平均的全距（與 10-13 矩陣同一把尺），也就是「小於系統之間差距十分之一的差異，算平手」。
另外會報 m 從 0 到 0.5 S 的整條曲線，結論不依賴單一 m。

每個介入、每個幅度報三個比例：答對率、平手率、答反率。

- **要求 1（該分出好壞）**：答對率 ≥ 80% 算通過。報每條階梯「第一個通過的幅度」＝偵測門檻；整條都沒過就寫「到最大幅度仍分不出來」。
- **要求 2（該平手）**：平手率 ≥ 80% 算通過。報每條階梯「最後一個還通過的幅度」＝容忍範圍；最小幅度就不過就寫「最小的改動就不平手」。

80% 與 0.10 S 都是暫定的，要在跑之前確定。

## 介入（單一變量，每個都是幅度階梯）

### 該分出好壞（預期 B 較差）

| 組 | 介入 | 幅度階梯 |
|---|---|---|
| 音高 | 錯音（隨機改成非調內音） | 1 顆、5%、10%、30%、100% |
| 音高 | 亂數音高 | 10%、30%、100% |
| 位置 | **音符隨機打亂位置**（音高不變，onset 重新亂數放） | 10%、30%、100% |
| 位置 | 打亂音高順序（節奏不變） | 2 s 區塊內、全段 |
| 節奏 | onset jitter | ±10、30、80、200 ms |
| 節奏 | 速度不穩（每拍隨機 ±x%） | 5、15、30% |
| 爆音 | **一顆音符變成爆音**（該音符 velocity 127＋只對該音符 hard clip） | 1 顆、3 顆、10 顆 |
| 結構 | 區塊打亂、逆行 | 0.5 s、2 s；全段 |
| 訊號 | click、dropout | 1、5、50 次／s；20 ms × 1、5、20 處 |
| 訊號 | 白噪音 | SNR 40、30、20、10、0 |
| 訊號 | clipping、bitcrush | 6、15、30 dB；8、4、3 bit |

「錯音 1 顆」「爆音 1 顆」是故意放的最小幅度：人一聽就知道哪裡錯，指標大概分不出來，正好量出偵測門檻在哪。

### 該平手（預期 |Δ| ≤ m）

| 組 | 介入 | 幅度階梯 |
|---|---|---|
| 完全相同 | 同一檔再評一次；同一檔放在不同 batch 組成／順序中評 | — |
| 音量 | 純增益 | −1、−3、−6、−12、−20 dB；+3、+6 dB（不 clip 的子集） |
| 極性 | 波形正負反轉 | — |
| 時間 | 開頭補靜音／平移 | 10、50、200 ms |
| 格式 | PCM_16、重採樣 16k→44.1k→16k、MP3 320k | — |
| 音樂上不重要 | 移調、整體速度 | ±1 半音；±2、±5% |
| 換 SoundFont | 同一份 MIDI 換另一個鋼琴取樣 | — |

極性反轉在聽覺上完全相同；音量、補靜音、格式這幾項只要不平手就是指標的缺陷，不需要人類評分來判斷。
移調、速度、換 SoundFont 是「我們認為不重要」，要使用者確認是否放在這一組。

**平手組也套在真實錄音與 TTM 輸出上**（只有訊號層的介入）：MusicCaps 真實 500 首、ours CFG3＋neg 500 首、MusicGen 500 首。
使用者舉的例子（同一首只改音量）就是這一格，在生成音訊上量比在 MIDI 上量更貼近實際用途。

### 底線（比白噪音更差）

| 刺激 | 說明 |
|---|---|
| 純 ±1 二值雜訊 | 每個取樣點隨機 ±1 |
| 純 0／1 二值雜訊 | 每個取樣點隨機 0 或 1（含直流） |
| 方波 | 100 Hz、1 kHz，±1 |
| 直流 | 常數值 |
| 數位靜音 | 全 0 |
| 單一正弦 | 1 kHz |
| 正弦掃頻 | 20 Hz–8 kHz |
| 脈衝串 | 每秒 10 個滿刻度脈衝 |

每一種做兩版：響度對齊 −30 LUFS（靜音與直流做不到，照實記錄），以及不對齊的滿刻度原樣。
預期全部低於 clean，且不高於純白噪音；任何一個在某指標上高於白噪音、甚至接近 clean，都直接列出。
