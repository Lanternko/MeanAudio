# 199 攻擊的客觀改變量：給 197 兩張表補一欄（2026-11-25 預登錄）

來源：另一位研究員對 197 簡報的建議（`../meetings/2026-11-25_peer_feedback_objective_distance_reference_free.md`）。
197 的表只有評分器的 Δ，沒有「這個處理把音檔改了多少」。這條線補上後者，並依它把攻擊分成「小改變（品質攻擊）」與「換了音樂（內容替換）」。

eval-only。不訓練、不重評 A1／PQ／CE／CMI-RM；評分器的 Δ 直接讀 197 已收線的 summary。
無人類評分。改變量只回答「數學上差多少」，不回答「聽起來差多少」。

- **表 2 A 區**：MAESTRO 150 段 × 2 SoundFont × 12 介入，參考＝同段同 SoundFont 的乾淨版。

## 2. 改變量定義（逐段，配對同一段的原版 x 與處理後 y，16 kHz）

| 代號 | 層 | 定義 | 範圍 |
|---|---|---|---|
| `rho` | 訊號 | 最佳延遲（±0.6 秒）＋最佳純量增益對齊後，y 的能量中 x 解釋不了的比例：ρ = min ‖y − g·x(τ)‖² / ‖y‖² | 0＝相同，1＝無關 |
| `mel` | 訊號 | 同一延遲對齊、各自正規化到相同 RMS 後，64 頻帶 log-mel（25 ms／10 ms，底 −80 dB）的平均絕對差（dB） | 0＝相同 |
| `d_clap` | 嵌入 | 1 − cos（LAION-CLAP 音訊嵌入；與 `eval_metrics.py` 同一個 checkpoint、同樣 48 kHz＋int16 輸入） | 0＝相同 |
| `d_mert` | 嵌入 | 1 − cos（MERT-v1-95M，沿用 133 的 `embed_mert_batch`） | 0＝相同 |
| `fd_clap` | 分布 | 該列 1,000 段對原版 1,000 段的 Fréchet 距離（CLAP 嵌入）。只當描述，不進分類 | — |

- `rho` 與 `mel` 依設計對純增益不變；`rho` 另對整段平移不變。所以 ±6 dB、前補靜音在訊號層應接近 0。
- 20 秒刺激（`ctr_snr10`、`side_snr10`，參考＝`ext`）：訊號層算整段；嵌入層取前後兩個 10 秒窗各算一次再平均。
- **不用 MuQ 嵌入**（不拿被攻擊的評分器量自己的攻擊）。CLAP 與 MERT 都不是 197 四個評分欄的骨幹。
- CLAP 批次：所有片段等長。smoke 時核對批次與逐檔的 cos 差；最大差 > 1e-4 就改逐檔。

## 3. 尺：兩條校正階梯（每個底都做）

改變量的單位沒有直覺意義，所以用兩條已知順序的階梯當尺：

- **混入無關音樂** `mix_r{24,18,12,6,0,m6,m12,m18}`：y = 原版＋同一個底的另一段（固定錯位配對），另一段比原版小 r LU，相加後鎖回 −30 LUFS。r24 幾乎沒改，m18 幾乎整段換掉。
- **白噪** `wn_snr{40,30,20,10,0}`。
- 兩個端點：`identity`（y＝x）、`other_clip`（y＝同一個底的另一段）。MeanAudio 三個底另加 `other_seed`（同 prompt、另一個 seed）。
- 表 2：`other_excerpt`（同 SoundFont 另一段）、`other_bank`（同段換 SoundFont）、以及同樣的 `mix_r*`（混入另一段的乾淨版）。

報告時每個改變量另給**正規化值** C = 該列中位數 ÷ `other_clip` 中位數（0＝沒改，1＝換成無關的一段），以及**等效混入量**：在 `mix_r*` 階梯上內插出「相當於混入一段小多少 LU 的無關音樂」。

## 4. 先驗收改變量本身（判例 M4）

改變量也是新指標，先過以下三關才進表；不過的那個代號整欄剔除並寫明：

1. `identity` 的值 ≤ `mix_r24` 中位數的 1/10。
2. 兩條階梯的中位數嚴格單調（6 個底都要）。
3. `other_clip` 中位數 > `mix_r0` 中位數 > `mix_r12` 中位數（6 個底都要）。

這三關只證明它排得出「混入多少無關內容」的順序，不證明它等於人耳感受到的差異。

## 5. 分類（先登錄）

只用通過第 4 節的嵌入層代號（`d_clap`、`d_mert`）判，逐底判、再數底數：

- **小改變**：兩個嵌入距離的中位數都 ≤ 該底 `mix_r12` 的中位數（改變量不超過混入一段小 12 LU 的無關音樂）。
- **換了音樂**：任一個嵌入距離的中位數 ≥ 該底 `mix_r0` 的中位數（至少等於等響混入另一段音樂）。
- 其餘：**中等**。
- 一列的標籤＝6 個底的多數；不到 4 個底同標籤記「依底而定」。
- 兩個嵌入代號如果只剩一個通過驗收，就只用那一個；都沒通過則不分類，只報訊號層。

訊號層（`rho`、`mel`）不進分類，只並列。理由：移調／變速在波形上與原版幾乎不相關，但音樂內容相同；訊號層會把它們判成最遠。兩層分歧本身是要報的結果。

## 6. 預期（先寫下，事後對）

| 列 | 預期 |
|---|---|
| ±6 dB、前補 0.5 秒靜音 | 訊號層 ≈ 0；嵌入層很小 |
| `side_snr10`（MuQ 視窗外加噪） | 改變量明顯大於 0，A1 卻逐位元不變 → 盲點型 |
| 低通 6 kHz、250 Hz ＋10 dB | 小改變 |
| 移調 ±1／±2、變速 | 訊號層接近 1；嵌入層小到中等 |
| `osynth_r18`、`sine1k_r18`、各種小聲疊入 | 小改變（r18 ≤ r12 的尺） |
| `pno0`（等響調內鋼琴琶音） | 換了音樂或接近 |
| MIDI 錯音 10%／30%／100% | 嵌入層隨劑量上升；100% 可能到「換了音樂」 |
| MIDI 移調 ±1、八度 | 訊號層大、嵌入層未知 |

## 9. 不能宣稱的事

- 改變量小不代表人聽不出來；「主觀上變差」仍沒有人類證據。
- CLAP／MERT 自己也有盲點（133：MERT 對極性、提前 10 ms 不具不變性），所以用兩個嵌入＋兩個訊號量並列，不單押一個。
- 分類門檻（r12、r0）是事先指定的慣例，不是聽感閾值。
