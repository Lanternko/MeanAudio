# NegMF lq100：把 `Low quality recording.` 放進 S2 ∅ 分支（109–111）

2026-10-07 登錄。084 NegMF 的第四個 arm，除了引導文字以外，設定和 rev100（092–094）逐項相同。

## 問題

`Low quality recording.` 這個措辭在三種位置上的效果差很多：

| 位置 | 量到的效果（PQ lvl30） |
|---|---|
| 推論期負向，nmv2pair control（cfg3_lqneg，3 seed 全量） | G_lqrec −0.007（各 seed +0.057／−0.092／+0.015）。fidelity8 是 G_neg ≈ +0.83 |
| 081 訓練期前綴標籤（語料最差 20% 的 caption 加前綴） | 差中差 +0.98；扣掉措辭劣勢後的乾淨 E1 是 +0.43（106） |
| NegMF S2 ∅ 分支 | **沒測過**。只測過 fidelity8（N100，E1 +0.948）和 reversed（rev100，E1 +0.36） |

Stage C 量到 R_train 0.38 ≈ R_inf 0.31：同一段文字，放進 ∅ 分支訓練拿到的增益，和放在推論期負向拿到的增益，比例差不多。

本實驗檢驗這個對應能不能推到一個推論期幾乎無效的措辭：
- 如果能，lq100 的 E1 應該 ≈ 0。
- 如果訓練期放置會把這個短句「放大」，E1 會明顯大於 0。這時 R_train ≈ R_inf 只對長串領域文字成立。

## 設計

- **起點**：nmv2pair control 自己的 S1 `ckpt_last`（100k）。3 個 seed（14159265／16180339／27182818），和 control 及 rev100 共用。
- **S2**：50k 步，語料是 `slot0clean_nmv2matched`（和 control 相同，**沒有任何品質前綴或 PQ 資訊**），recipe 和 seed 都與 control 相同。
- **唯一改動**：MeanFlow CFG 訓練目標裡的 ∅ 分支文字換成 `Low quality recording.`，套用在所有樣本（t_min 0）。
- **特徵**：`weights/negmf_084/lqrec_{t5,clap_c}.pth`，用 `build_negmf_guide_feats_084.py` 產生。G0b 通過：5 個有效 token，min cos 0.99999988，CLAP cos 1.0。
- **eval**：
  - arm 跑 MF25 cfg0 和 cfg3_neg（fidelity8），兩格都算 FAD；再跑 1-NFE cfg0。所有格都做 −30 LUFS 重評分，評完刪音檔。
  - control 的格都已經存在，包括 cfg3_lqneg、它的 lvl30 和 FAD，不重跑。
- **action**：共用 `scripts/training_pipelines/negmf_084_action.sh`（新增 `lq100` case）。per-seed 腳本是 `negmf_084_lq100_s<seed>.sh`。

## 主要讀數與判讀（預登錄）

**主要讀數**：E1(lq100) = lq100 cfg0 − control cfg0。PQ lvl30，逐 clip 配對，3 seed 合併。CI 用 10,000 次 clip bootstrap（seed 20261007），和 `negmf_084_analysis.py` 同法。

| 結果 | 判讀 |
|---|---|
| E1 ≥ +0.30 且 CI 下界 > 0 | 訓練期放置讓這個措辭有效，推論期的 ≈0 推不到訓練期 → R_train ≈ R_inf 不是一般規律 |
| \|E1\| < 0.15 且 CI 跨 0 | 與推論期 ≈0 一致；R_train ≈ R_inf 再多一個支持點 |
| 其他 | 部分，照實報數字，不下結論 |

**次要讀數**（不作判讀依據）：
- C_lq = lq100 cfg0 − rev100 cfg0，以及各 seed 的正負號
- E1(lq100) / E1(n100)，對照 R_inf(lq) = G_lqrec / G_neg
- 排除靜音 clip 的 E1
- CE／CU／PC／CLAP（CLAP 非劣性界沿用 084 的 −0.008）
- FAD、LUFS、crest、靜音數
- 1-NFE cfg0
- arm 的 cfg3_neg

### 預測

- E1(lq100) 約 0～+0.2，落在「與推論期一致」或「部分」。
- 依據：R_train ≈ R_inf，且 G_lqrec ≈ 0。
- 反方向的理由：081 的 LQ 前綴標籤在訓練期有效（乾淨 E1 +0.43），代表模型「能學會」這個短句。只是 081 是把它和真的低 PQ 音訊配對，這裡只放在 ∅ 分支，不碰任何音訊。

## 限制

- 只有一個短措辭。和 fidelity8／reversed 比，長度（5 個 token 對 16～20 個）也不同。E1 小，可能是「短」造成的，也可能是「措辭」造成的；本實驗分不開。107 的無關文字結果可以輔助判讀（無關文字較長）。
- 和 084 一樣，PQ 是被 AES 引導的端點。FAD 必報。

## 排程

- p2 109／110／111，每 seed 約 4.3 h（以 rev100 實測），排在 107、108 之後。
- 依規走 queue（> 30 min）。
- 使用者 2026-10-07 授權：「測一下 LQ」。
