## 結論

1. **063 的「越小聲 PQ 越高」只在 −21～0 dB 成立。** PQ 與 CU 在 −21 dB 到頂（bootstrap 峰值位置 PQ 100%、CU 98% 落在 m21），之後一路下降，約 −96～−108 dB 貼到靜音分數。CE、PC、CLAP 在原音量（z0）最高，越小聲越低，沒有頂點。
2. **三種底線都量到了，而且位置不同。** 評分器底線（float 輸入也躲不掉）：AES 約 −96～−108 dB、CLAP 約 −84～−120 dB。PCM_16 格式底線：PQ/CU 從 −42 dB 開始可測、CE −66、CLAP 實質從 −66、PC −90。LUFS −70 門檻：以 L\* 繞過，不影響其餘結果。
3. **用 limiter 向下壓來躲格式底線不划算。** 在同一個 L\* 下，limiter 版的 PQ 在 D18～D72 每一格都比純量衰減差（−0.57 → −0.07）。它省下的格式損傷最多只有 0.002 PQ，比處理代價小兩個數量級。
4. **deliverable 的 PCM_16 在極小聲時分數反而高於靜音。** Q 模式在 m90 以下 PQ 固定在 7.249，靜音是 6.735：libsndfile 的 floor 量化把訊號變成 1-bit 殘影，AES 把它讀成「有聲音」。

## 底線位置

| 指標 | 評分器底線（腳本判準） | 格式底線起點（腳本判準） | 靜音分數 |
|---|---|---|---|
| PQ | 120（m108 差靜音 0.011，剛好超過 0.01 容忍值；實質 ≈ −96） | 42 | 6.735 |
| CU | 108 | 42 | 6.453 |
| CE | 108 | 66 | 3.235 |
| PC | 108 | 90 | 1.703 |
| CLAP | 120 | 18（**判準假象**，見下） | 0.146 |

**CLAP 的「18」是定義造成的假象。** z0 時 canonical CLAP 比 float 低 0.0061（預註冊已記的常數偏移），但這個偏移在 −18 dB 就消失了：m18 的 Q−F 是 −0.0001，−24～−54 dB 還變成 Q 略高（+0.001～+0.005）。所以「(Q−F)−(Q−F)\_z0」在 m18 就超過容忍值，但那是偏移消失，不是格式損傷。
真正的 CLAP 格式損傷從 −66 dB 開始（Q−F −0.010），−72 dB 擴大到 −0.024。
這也修正了預註冊「CLAP 偏移是常數」的說法：**這個偏移只在接近滿刻度時存在**，arm 之間響度不同時不能當常數扣掉。

所有 D−m 的 CI 寬度都在 ±0.01 PQ 內。

- 要讓 L\* 只降 18 dB，limiter 必須壓掉 25 dB 的峰值，因為它只能削峰。這是極端處理，CE −0.68、CU −0.52，只有 PC +0.23（與 064 同向：limiter 只讓 PC 升）。
- 格式損傷 limiter 在 D18～D48 確實較小，但差距最多 0.002 PQ，處理代價是它的數百倍。到 D60 反而是 limiter 較大。
- D84 PQ +0.036 不是 limiter 較好。兩邊在 Q 模式都已經是 1-bit 殘影，那個差是殘影型態不同。
- 同一條 limited 波形調回原音量後，PQ 處理代價在 D36 以後飽和在約 −0.77，比 064 的 T14（−0.22）大，因為這裡的 GR 是 25～91 dB。

## 附帶觀察

- F 模式 CU 在 −84～−96 低於靜音分數；PQ m96 6.726 也低於靜音 6.735。代表趨近底線時不是單調貼近，但差距 ≤ 0.01。
- CLAP F 在 −90 dB 為 0.135，低於靜音 0.146：極弱訊號比全零更「不像 caption」。

## 對既有結論的影響

- **063**：「PQ/CU 越小聲越高」要加範圍「−21～0 dB」。實務上生成音檔在 −14～−30 LUFS，所以 arm 間比較仍落在單調區，063 的「先鎖 LUFS」建議不變。
- **064**：向下方向的 limiting 也一樣傷 PQ/CU/CE/CLAP、只升 PC，與向上方向一致。
- **CLAP 絕對值**：canonical 路徑的 −0.006 偏移只在接近滿刻度時存在。響度差很大的 arm 比 CLAP 時，偏移本身也會差到 0.006。

## 限制

單一 checkpoint、單一 generation seed（051 baseline 音檔）；單一 limiter（x42-dpl, release 50 ms）。
−36 dB 以下的音量在實際使用中不會出現：本實驗量的是評分器與格式的行為，不是聽感。
預期是看過 32 片段 pilot/smoke 才寫的，而這 32 片段也包含在全量裡。
