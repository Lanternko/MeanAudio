## AES 介入診斷（2026-10-03～05：095 失敗 → 099／100 診斷 → 101／102 修正版重跑）

目的：N100 比 control 多出來的 AES PQ，是不是對特定聲學成分（雜訊、安靜段、高頻、某個 stem）的反應。做法是對已生成的音檔做介入，看 **gap change** =（N100 介入 − N100 基線）−（control 介入 − control 基線）。負值代表介入後 N100 的優勢變小。只用既有音檔，不重訓、不重生；沒有 FAD 和人類評分。

### 095 為什麼失敗、099／100 查到什麼

- 095（`aes-negmf-formal-recovery-20261003`）卡在 gain-control gate：`QUB_vpjogmo_170`（N100 s27182818 CFG0）原音和 −6 dB 版本分別正規化到 −23 LUFS 後，PQ 還差 0.022，超過上限 0.01。
- **099**（cuDNN TF32 開，23 個來源）：同一輸入重複推論差 0；兩個 gain 版本差 0.022～0.023，單獨跑、配對跑、混批跑都一樣 → 差距來自 **normalizer**，不是 AES 的非決定性。舊 normalizer 下兩版 RMS 差 0.537 dB，原因是 BS.1770 絕對門檻選到不同分支。新 normalizer（先把 RMS 固定在 −23 dB，再跑原本的 −23 LUFS 求解）把差距降到 ≤ 0.001。另外，批次組成會讓分數漂移最多 0.028。
- **100**（同 099，cuDNN TF32 關）：批次漂移降到 3e-6，新 normalizer 的 control 差距降到 6e-6 → 099 的批次漂移是 **cuDNN TF32** 造成的。
- 舊 gate 仍判 failed，不回填。101／102 是新契約（固定 RMS 的 normalizer＋嚴格 FP32），門檻不變。
