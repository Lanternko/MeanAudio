## 6. 可以寫與不可以寫

可以寫：
- 在真實演奏的 MIDI 上，AES 四軸與 MEva 對音符層介入（錯音、節奏 jitter、速度跳變、掉音、結構打亂）的反應幅度是 PQ ≤ 0.18、CE ≤ 0.31、MEva ≤ 0.26，
  與「不該影響品質」的殘響／音色／移調同量級；對訊號層破壞的反應是 1–4 分。
- AES CE 與 CU 沒過預先登錄的敏感度門檻；CU 另外對移調與殘響有反應。
- MEva 與 MIR 的 pulse_clarity／key_cnn_conf 過門檻；後兩者各只對節奏類／音高類介入有反應。
- FAD 對音符層介入的距離與對半底線同級；換 SoundFont 的距離比任何音符層介入都大。

不可以寫：
- 「AES／MEva 聽不到錯音」— 有反應，只是小；也沒有人類評分說錯音該扣多少。
- 「指標錯了」— 只能寫與預先登錄的預期不一致。
- 紅綠燈位置當成系統排名或品質結論。
- 掉音／力度亂數讓分數上升是「偏誤」— 沒有人類對這些版本的評分。
