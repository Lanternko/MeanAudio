# 203 移調／變速在 Music Arena 反向的原因：結果（2026-11-25）

設計：`../arena_pitch_reversal_203_20261125.md`。數值：`arena_pitch_reversal_203_summary.json`。
eval-only，Arena 每系統 50 段共 748 段，7 個條件全部在 16 kHz 下評 MuQ A1／A3a，bootstrap 5,000 次。**無人類評分。**

## 結論

1. **預登錄判定：H1 部分成立。** 把移調後的頂端頻段（7.1～8 kHz）清空確實讓 A1 加分（E +0.087，CI 不跨零），但 Arena 音檔降到 16 kHz 後整體仍沒有翻回正的（T −0.022，CI 跨零）。頻寬解釋了反向的一部分，不是全部。
2. **另一半是素材本身的 A1 高低**（事後發現，非預登錄）。逐段 T 與未處理 A1 的相關是 −0.60。未處理 A1 低的系統（MusicGen small／medium 3.4～3.5、Magenta RT 3.8～4.0）降到 16 kHz 後移調 −2 是 +0.18～+0.30，與 197 的 MusicGen 底 +0.226 相符；A1 高的系統（4.7～5.0）是 −0.09～−0.25。197 的底 A1 都在 3.0～3.5，落在會加分的那一側。
3. **「偽裝的低通」這個機制說法沒有被支持。** 在降到 16 kHz 的 Arena 音檔上，只做 7,127 Hz 低通是扣分（L −0.097），不是加分。E 與 L 逐段相關 0.68，但平均差了約 0.18；清空頂端為什麼在移調後加分、單獨做卻扣分，這裡沒有解釋。
4. **變速 0.9x 與取樣率無關。** 在 16 kHz 上做（−0.148）與在原生取樣率做再降（−0.153）幾乎相同，15 個系統 14 個為負。197 的 +0.065 是 197 那批底的特性（202 已判這格不穩健）。
5. 200 在 Arena 看到的低通 6 kHz 加分（+0.387），主要來自切掉 8 kHz 以上：單是降到 16 kHz 就 +0.199；降完之後再往下切到 7.1 kHz 是扣分。

## 限制

- 素材 A1 高低這條是看完資料才提出的，沒有預登錄，也沒有分開「系統」與「A1 水準」（兩者高度綁在一起）。
- 響度沒有完全鎖回：四個 rubberband 條件平均比未處理小約 0.5 LU（個別最多 7 LU，峰值上限造成）。只留響度差 < 0.5 LU 的 550 段重算，T −0.030、P −0.123、E +0.093、L −0.093，結論不變。
- 子集 748 段，不重算一致率與排名；不改 197／200 的任何判定。
- A3a 的拆解方向不同（E −0.126、T −0.187），這裡只對 A1 下結論。
