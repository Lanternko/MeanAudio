`lp6k` 逐底（ΔA1／ΔCE／ΔPQ，括號為 95% CI）：

| CFG3＋neg × 3 | +0.155～+0.204 | −0.11～−0.13 | −0.21～−0.24 | +0.05～+0.07 |

- **在能聽的音檔上成立**：教授 11-10 第 2 點要的「好音檔壓掉高頻、分數反而升」在 CFG3＋neg 三 seed、MusicGen、MusicLDM 都成立，幅度和 CFG0 相同（+0.15～+0.20）。真實錄音只有 +0.061，CI 下界 +0.043 差一點沒過 m 0.055。
- **A3a 只跟一小部分**：A3a MI 的轉移比在能聽的底約 0～0.3（MusicGen／真實貼零），CFG0 約 0.5 → 這次的加分主要在 A1 頭上，比 187 的 `general_shift` 專一。
- **劑量曲線不單調**：6 kHz 頂、5 kHz 掉到 0 以下（真實 −0.13、MusicLDM A3a −0.20）、4 kHz 部分回升（CFG0 +0.04～+0.06、CFG3＋neg +0.03～+0.08）、3 kHz 以下全負。5 kHz 的谷在 A1 與 A3a 同時出現（A3a −0.11～−0.20），兩個頭共用 MuQ 骨幹，所以比較像骨幹特徵在 5–6 kHz 一帶的反應，不是 A1 頭的雜訊。7 kHz 到 4 kHz 每格的濾波器都是同一個 8 階 Butterworth、標稱截止處 −6 dB（實測見 `filter_response.json`），不是濾波器實作差異。原因未解釋。
- 預登錄預期「A1 在 6–5 kHz 最高、4 kHz 以下回落」只對了一半：6 kHz 是頂，但 5 kHz 已經在谷底。預期「CE 隨截止單調降」大致成立（真實錄音 5 kHz 是唯一例外）。

## 一句話 EQ 與 high pass

- 15 格中只有 `eq250_p10`（平均 +0.065，成立 2/6：MusicLDM +0.091、真實 +0.078）與 `eq2k_m10`（+0.039，成立 0/6，只有 MUSDB success）有正向讀數；其他 EQ 格平均都在 ±0.04 內。
- 預登錄預期「125／250 Hz ＋10 dB 可能加分」：250 Hz 有、但很小；125 Hz 只有 +0.030。預期「4 kHz −10 dB 類似低通」不成立（−0.014）。
- high pass 一律扣分：100 Hz +0.011、200 Hz −0.144、500 Hz −0.610。
- `eq250_p10` 的獨立守門：PAM 在每個底都 ≥ 0（+0.00～+0.01），真實與 MUSDB 上 PAM 與 CMI-RM caption 都不動（`independent_blind`）。所以它是「只有 A1 看得到、而且很小」的一句話手法，比低通更像盲點，但幅度只有低通的四成。

## 其他評分器（`lp6k`）

- **AES PQ／CE 全降**：低通在每個底都扣 PQ（−0.21～−0.90）與 CE。預登錄預期「AES 內部 16 kHz，低通可能不扣 PQ」不成立。目前能騙到 PQ 的仍只有疊加循環音（188／189）。
- **CMI-RM caption 每個底都判為變差**（−0.10～−0.18，超出平手帶）。
- **PAM 依底而定**：MusicGen −0.03、MusicLDM −0.04、真實 −0.01（判為變差）；MeanAudio CFG3＋neg +0.01、CFG0 +0.04（反而小升）。
- CLAP −0.002～−0.009；SongEval 五維 −0.01～−0.06（tier 3 只有 base／lp6k／lp4k／lp2k／hp200）。

## 結論

1. **最簡單的攻擊就是 6 kHz 低通**：一行 Butterworth 低通，在能聽的生成音檔（CFG3＋neg、MusicGen、MusicLDM）上 A1 +0.15～+0.20，約 0.3 S；A3a 大致不跟。這是 179／182 的 +0.15 在更多底上的複製。
2. **刷不得更高**：截止往下壓沒有更好，5 kHz 反而在谷底；6 kHz 附近是後製低通的上限。E2 判 `6k_is_top`。
3. **一句話 EQ 很弱**：250 Hz ＋10 dB 只有 +0.065、2/6 成立；high pass 全扣分。
4. **同一手法打 AES PQ 失敗**：PQ、CE 每格都降；CMI-RM 每格看得到。所以「低通騙分」是 MuQ 專有的弱點，論文可把它和 PQ 的弱點（疊加循環音）分開寫。
5. **語料外沒有複製**：MUSDB 上 +0.025，不顯著；真實 MusicCaps 錄音只有 +0.061。加分集中在 16 kHz 生成音訊，與 182 的觀察一致。

限制：無人類評分，「低通後人聽起來沒有變好」目前只能引用教授的聽感（人類聽測已登錄並發布評分頁，等聽者：`docs/experiments/human_listen_lp6k_20261113.md`）；5 kHz 谷的原因未查；EQ 用 Q = √2，兩個八度外仍有 ±0.3～0.4 dB 的殘餘響應。
