# 196 AES CE 能推多高 — 結果（2026-11-14 收線，p2 196）

設計：`docs/experiments/ce_push_196_20261114.md`（不要求 CE 專一；PQ／A1 跟漲不算失敗）。輸出 `~/eval_output_nvme/ce_push_196/`（`summary.json`、`summary_table.md`、`selection.json` 在 test 前凍結）。S_CE 1.1905、m_CE 0.119；test 800 段 × 9 底，bootstrap 5000。

## 評分：4/5 大致達成（推得動，但最大推力的格是把音樂換成合成聲）

**核心結論**：CE 推得動，6 個能聽的底全部成立。dev 凍結的 `star_any` 是 `synm18`，也就是 key-matched e00 合成聲比底大聲 18 LU，實質上把音樂蓋掉。它把能聽的底 CE 平均推到 7.21（真實底 6.03），ΔCE +0.79，但 CLAP −0.13～−0.17。`star_keep` 是 `syn6`（合成聲比底小 6 LU），CLAP 只掉 −0.01～−0.03，ΔCE 一樣 6/6 成立（+0.25～+0.67）。濾波族（低通／傾斜）推不動 CE，`lp4500` 0/6。整格換成合成聲（`synonly`）CE 7.63～7.69，仍到不了 195 黑箱搜尋的 8.09。

## 關鍵數據（test，能聽的 6 底）

|---|---|---|---|---|---|

| `lp4500`（best_filt） | 0/6 | 平均 6.37 | −0.15～+0.03 | ≈0 | PQ −0.13～−0.34、A1 +0.10～+0.13 |

- CE 已經高的底（CFG3+neg，6.83）推得少：`synm18` 只多 +0.37～+0.46、PQ 不漲；原本低的 MusicLDM／CFG0 推最多（+1.25～+1.53）。
- 在 CE 上越大聲越好：syn12 → syn6 → syn0 → synm6 → synm12 → synm18，dev ΔCE 單調升（+0.25 → +0.70），CLAP 同步單調降。CE 沒有上限頂點，只是越來越接近「純合成聲」。
- 鋼琴琶音 `pno0` 是唯一一個除了 CLAP 以外，所有品質評分器（含 CMI-RM quality）都說變好的簡單後製。

## 解讀邊界

- 沒有人類評分。CE「推得動」不代表內容變好：`synm18` 的 CLAP 掉到幾乎是換曲的程度。
- e00 來自 195 對 CE 的黑箱搜尋（D3），不是外部可得的配方；`syn*` 族是在 CE 上選出來的聲音。
- test 的 base 格直接複製 195 per_clip（D6）。
