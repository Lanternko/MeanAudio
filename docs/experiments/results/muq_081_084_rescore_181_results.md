# 總評

**4/5 大致達成 有部分退步（建議採用）**

核心結論：預登錄假說**成立**。三個 PQ 導向手法（081 E1、081 E3、084 N100）的 MuQ A1 MI 都「跟著漲」，三 seed 同號、平均是門檻 m（0.055）的 4–5 倍，A3a 也一樣。所以訓練期刷 AES PQ 會連帶刷高 MuQ，不需要新訓練就有「訓練可以刷 MuQ」的例子。扣一分是因為漲幅只有 PQ 的一半左右（以各自的系統間全距換算，R 0.47–0.53），而且 081 的最佳格在 MuQ 上仍然輸 MusicGen 和真實錄音。
