# 總評

**3/5 一半一半（建議當分析結果採用；疊加不當攻擊結果）**

核心結論：「MuQ 到底喜歡什麼」有了答案，但它不是一個能一句話講完的簡單屬性，所以也做不成簡單的疊加攻擊。R 臂那個聲音的高分來自一組很特定的組合（固定的幾個音高＋寬頻頻譜＋週期內的時間順序），移 2 個半音就幾乎歸零，而且它落在真實音樂的特徵範圍之外，10.9 分是線性頭往外推出來的。用公式手工合成（三個分音＋低音）最高只到 5.3 分。把這個手工聲音小聲墊在真實音樂底下，A1 只漲 +0.13，而且 MuQ 的另一個頭 A3a 跟著漲，預登錄判定是 `general_shift`，不是 `exploit`。

**關鍵數據與例子**

- **為什麼能超過 5、MuQ 喜歡的是什麼。** A1 的頭是沒有上界的線性回歸。R 臂聲音送進這個頭的特徵，長度是真實音樂的 2.2 倍（24.5 對 11.3）、離真實音樂分布的距離是真實音樂第 90 百分位的 1.45 倍——高分是在訓練資料範圍外外推出來的。拆解（52 種版本 × 64 段，保留率 ρ＝留下多少比例的增益）：原樣處理 1.00；**移調 ±2 半音 0.01／0.35**、把 0.16 s 週期內的順序打亂 0.12、時間反轉 0.40、變速 0.5×～2× 都 ≤ 0.39、只留任何一個倍頻程都 ≤ 0.18、低通 2 kHz 0.37。反過來，把單一屬性移植到別的聲音上都沒用：脈動包絡套在粉紅噪音 −0.09、音色頻譜套在 control 0.13、只留音色去掉脈動 0.15。**0.16 s 的脈動本身不是得分來源**——把包絡抹平還留 0.60。所以答案是「這幾個音高＋寬頻頻譜＋固定順序」的組合，缺一不可，沒有單一屬性足以帶分。
- **手工合成只重現三成，疊加有效但不是 A1 專有。** 190 個公式合成的聲音裡最高分是「201／332／395 Hz 三個分音＋62 Hz 低音、低通鋸齒波」，A1 5.08～5.27（ρ 0.30），高過 90% 的真實 MusicCaps 錄音（第 90 百分位 4.77）但離 R 的 10.9 很遠 → `simple_recipe_partial`。換成 C–E–G 和弦只有 0.94，白噪音 1.93。把它小聲墊在真實音樂下，A1 +0.128，其他四種對照聲都是下降或持平（比最好的對照多 +0.105，CI 不跨零），所以效果是這個聲音特有的；但 A3a 跟著漲（T 0.64）。調大聲 A1 最多 +0.36（等響），這時 CE −1.26、CLAP −0.054，已經不是「偷偷墊」。
- **R 臂片段的疊加才是「A1 漲、A3a 不跟」，但只在我們自己的生成音檔上過門檻。** 生成音檔上小聲 +0.189、A3a 只 +0.031（T 0.14），比音樂大聲 6 LU 時 +1.54、23% 的片段超過 5 分；CE 同時 −0.33～−2.29。真實錄音上小聲格的 CI 下界 0.054 差一點沒過 m。這一格是次要格、只用一段 R 片段、素材來自對抗式微調，照教授的標準不算簡單可解釋。生成音檔本身也比較容易被推高：連 click 與另一首音樂在等響時都讓它 +0.38／+0.22。FAD（生成底、小聲格，描述用）7.60 → 8.18（手工合成）／8.02（R 片段）。

補充讀數（描述用）：

- **劑量軌跡（Part A，1 步取樣重生 17 個 checkpoint）**：10～160 步輸出仍隨 prompt 變（段間輪廓 cos 0.55 → 0.63），A1 2.93 → 4.53；到 500 步已經塌成同一個聲音（cos 0.98、A1 9.45、全部 > 5），之後到 3,000 步只再漲到 10.9。兩個訓練 seed 收斂到相同週期（0.155 s）但不是同一個聲音（互相 cos 0.84）；λ 0.3／1.0 的週期是 0.17 s。吸引子是一族相近的聲音，不是唯一解。R 臂 3,000 步的 CE 3.0（control 5.6）、PQ 7.5（control 6.8）。
- **其他拆解**：R 聲音只佔片段 50% 時間留 0.23（對時間佔比低於線性，不是取最大值的池化）；−20 LUFS 比 −30 LUFS 高（ρ 1.20，A1 12.5），−40 LUFS 0.91；挖掉 125–250 Hz 或 4–8 kHz 各留 0.76／0.74，高通 300 Hz 以上 ≤ 0.14。
- **真實音樂上的同向傾向（Part F，2,000 筆 MusicCaps）**：A1 與週期性強度 +0.25、200–500 Hz 占比 +0.21、諧波比 +0.21、第三分音 +0.21、頻譜重心 −0.22（Spearman）；9 個特徵的線性模型只解釋 20% 變異。R 的這些特徵落在真實分布的第 97～100 百分位 → 預登錄判定 `exaggerated_preference`：R 把真實音樂上本來就有的輕微傾向（偏暗、偏諧波、週期穩定）推到極端。真實音樂的 A1 最高 5.82（古典弦樂），本身也會超過 5；最低 0.75（觀眾聲很大的現場錄音）。
