# 180：Music Arena 拿掉 8 kHz 以上頻段後，MuQ 和人類投票的一致率（2026-11-05）

設計與預登錄判準：`docs/experiments/muq_arena_bandlimit_180_20261105.md`（2026-11-05 直接跑；評分中途兩次 OOM，原因是預載沒有上限，修好後從斷點續跑，續跑以段為單位）。數字：`muq_arena_bandlimit_180_summary.json`。F0 跟 r2 已存的 A1 MI 一致（3,998 段，max |Δ| 5e-7）。

# 總評

**3/5 一半一半（只採用為 A1 的偏誤證據，不採用「翻案」的說法）**

核心結論：預登錄的主判準勉強通過。A1 MI 把 8 kHz 以上濾掉之後，逐場 forced 一致率 0.626 → 0.649（+0.023，CI [+0.005, +0.042]），重採樣到 16k 也同號（+0.029）。所以 8 kHz 以上的內容確實讓 A1 在對戰裡判錯了一些場次。但這不等於幫寬頻大模型翻案：所有系統的分數都一起上升（+0.13～+0.35），系統排名幾乎不動（ρ 0.99），系統層級對人類 BT 的 τ 反而 0.524 → 0.505。A3a MI 完全沒有效果（+0.002）。

**關鍵數據與例子**

1,412 場決定票，人類天花板 0.742。括號是以 battle 為單位的 bootstrap 95% CI。

| 指標 | F0 forced | lp8k Δ | sr16k Δ | 系統 τ（F0 → lp8k） |
|---|---|---|---|---|
| A1 MI（主判準） | 0.626 | **+0.023** [+0.005, +0.042] | +0.029 [+0.010, +0.049] | 0.524 → 0.505 |
| A1 TA | 0.569 | +0.011 [−0.010, +0.031] | +0.016 [−0.004, +0.038] | 0.390 → 0.486 |
| A3a MI | 0.667 | +0.002 [−0.012, +0.015] | −0.004 [−0.017, +0.009] | 0.486 → 0.486 |
| A3a TA | 0.610 | +0.009 [−0.008, +0.026] | +0.010 [−0.008, +0.028] | 0.505 → 0.543 |

- **改善集中在頻寬落差大的對戰嗎？沒有。** 兩方 8 kHz 以上能量差 ≥ 6 dB 的 637 場：Δ +0.027；其餘場次 +0.021，兩者差不多。人類在這 637 場只有 47% 選頻寬較寬的一方。所以改善看起來是 A1 對高頻內容整體比較敏感，跟「寬頻系統被冤枉」沒有特別關係。
- **每個系統的 ΔMI 跟 8 kHz 以上能量正相關**（系統 Spearman：lp8k 0.55、sr16k 0.73），寬頻系統加分比較多。不過幾乎沒有高頻內容的 musicgen-small 用 lp8k 也加了 +0.26，可見 A1 對濾波處理本身也有反應，不只是看能量。
- **A1 加上低通之後（0.649）仍然低於 A3a 原樣（0.667）和 MEva（0.665）**。換成 A1+低通，在 Arena 上也不會排到比較前面。

**要你決定的事**

1. **（建議）把結果寫成偏誤定位的補充證據，不採用前處理**：論文寫「A1 在 8 kHz 以上會扣分，濾掉後逐場一致率 +2.3 點，但系統排名不變；A3a 不受影響」。也可以回覆 york135：分數確實升回來，但所有系統一起升，所以排名沒有翻。理由：效果小、只出現在一個變體，而且系統層級沒有改善。
2. 在 r3 加一格「A1+lp8k」當候選前處理，跟其他指標一起過閘門。只有想讓 A1 留在候選名單時才值得做，預期也贏不過 A3a。
3. 不再做任何延伸，直接收線。

不可寫：Arena 每場只有 1 票；只測 8 kHz 以上，4–8 kHz 不在這次範圍；結果只限這 15 個系統；主判準過門檻的幅度只有 0.003。
