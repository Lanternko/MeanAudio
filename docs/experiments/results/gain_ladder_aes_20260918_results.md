## 判讀

1. **PQ / CU：單調，沒有倒 U。** 在 −18 dB 到原檔的整段範圍，越小聲分數越高，
   而且在安靜端趨平（−18→−15 只差 0.013）、在原檔附近最陡（−3→0 差 0.052）。
   051 自然響度分組看到的倒 U 因此**不是**同片段振幅效應，是跨片段的組成差異。
2. **CE / PC：倒 U，最佳點在 −6～−3 dB。** CE 在 m6/m3 最高（相鄰階 m6→m3 CI 跨零），
   往安靜端大幅下降（m18 比頂點低 0.156）、往原檔小幅下降（−0.012）。PC 同型。
   也就是說**四個 AES 軸對響度的反應形狀不同**：PQ/CU 偏好安靜，CE/PC 有偏好振幅
   （LUFS 約 −25～−22），原始輸出 −18.75 LUFS 落在頂點偏大聲那側。
3. **CLAP 也對響度敏感，方向與 PQ 相反：越大聲越高。** 全量 −18→0 dB 共 +0.0229，
   原檔附近每 dB 約 +0.0018（m3→z0 +0.0055 [+0.0051, +0.0058]）。
   推論 seed 的 CLAP 底線是 0.0003，所以**兩個 arm 輸出響度差 3 dB，CLAP 就會差約 18 倍底線**；
   這與本專案宣稱過的若干 CLAP 差距同量級（例如 captioner-only control 的 +0.0073）。
   這是新發現，此前 CLAP 的增益敏感度從未被量過。
4. **響度對兩個主指標是反向 lever**：調大聲 → CLAP 升、PQ 降；調小聲反之。
   任何兩個輸出響度不同的 arm，在 CLAP 與 PQ 上會出現「一升一降」的假 trade-off。

## 對既有結論的影響

- **arm 間 PQ 與 CLAP 比較都必須先確認輸出響度相近。** 051 只說 PQ 要鎖響度；063 補上 CLAP 也要。
  反向的敏感度代表響度差會同時製造 CLAP 增益與 PQ 損失（或反之）。
- **既往結果的量級對照**：negprompt 的 PQ +0.95～+1.07 遠超任何合理響度差能解釋的量；
  但 CLAP 差距在 0.005 上下的比較（captioner、語料 arm）須回查兩 arm 的 LUFS。
- **不要用增益「修」分數。** 把輸出調小聲可以刷 PQ/CU，代價是 CE/PC 與 CLAP，
  這是指標缺陷不是音訊變好（機制見 `docs/metrics/audiobox_aesthetics.md`「已知限制」）。

## 限制

單一 checkpoint、單一 generation seed，沿用 051 的 baseline 音訊。範圍 −18 dB 到原檔（p6 子集到 +6 dB），
不可外推。p6 是選擇子集。CLAP 在 16 kHz 音訊上評分。AES 是確定性的，所以「放大方向」與
051 的衰減方向是同一組配對，本實驗新增的是範圍與形狀，不是方向。CI 跨零是證據不足不是等效。
AES 與 CLAP 都不是人類判斷。

> **2026-09-18 範圍補註（065 pilot，32 片段）**：往 −18 dB 以下延伸後，PQ 在 −18～−24 dB 附近到頂、之後下降，
> 約 −108 dB 收斂到靜音分數。所以上面「PQ/CU 單調、沒有倒 U」只在 −18～0 dB 成立，全範圍其實是倒 U，
> 頂點遠低於任何實際輸出音量。全量結果見 065（`docs/experiments/results/floor_ladder_aes_20260918_results.md`）：5,521 片段確認 PQ/CU 頂點在 −21 dB（bootstrap 峰值 100%／98% 落在 m21），所以單調範圍是 −21～0 dB。
