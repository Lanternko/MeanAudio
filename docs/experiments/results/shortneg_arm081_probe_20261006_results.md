1. **標籤專一性**，定義為 C(lqrec − k) − A(lqrec − k)：

   lqrec − lqnoisy 為 +0.44，≥ 0.19 且 CI 下界 > 0。依預登錄規則判定「標籤訓練對這串字有專一效果」。

2. **普遍敏感**：DiD(lqnoisy) +0.54 與 DiD(fid8) +0.44 都 ≥ 0.19。依規則判定「arm 對負向普遍更敏感」，標籤訓練放大的是整個負向槽。兩個條件同時成立。

## 預登錄以外的觀察（探索，單 seed）

- **在 arm 自己身上，標籤字並不是最強的短負向。** C 的 lqnoisy 比 lqrec 高 +0.108 [+0.087, +0.128]（lvl30）。所以「專一效果」的意思是：標籤字的**提升幅度**最大（從 control 的 ≈0 拉上來），不是標籤字在 arm 上**最有效**。
- **`low quality` 在 arm 上失效**：C 的增益是 −0.012，control 是 +0.199，DiD −0.21、CI 不跨零。這是預登錄以外最意外的一格。
  - 可能的解釋：訓練時 `Low quality recording.` 只以完整前綴出現，裸 `low quality` 被推離了那個方向。
  - 只有單 seed，未驗證。
- **stored null 的 CFG3 懲罰在 arm 上消失**：control 是 −0.13，arm 是 −0.02，DiD +0.11。
- **無關文字在兩個模型上都約 +0.5、DiD ≈ 0**：負向槽的「非空文字」基線效果沒有被標籤訓練改變。
