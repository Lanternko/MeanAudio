# 總評

**2/5 主目標達成 但是有副作用（建議不採用為攻擊結果；收線）**

核心結論：A1 獎勵微調只跑 60 步，就能把 MusicCaps 上的 A1 推高 +0.231（系統間全距的 0.42 倍），而且全部落在 1–5 量表內（沒有任何一段超過 5，夾住後數字不變）——「把無上界的 A1 夾住就好」這個反駁不成立。但 A3a、PQ、CE 在每個劑量都跟著漲（轉移比 0.55–0.72，門檻 < 0.5），預登錄判定是 `general_shift`，不是 `in_range_exploit`：小劑量的 A1 獎勵推的是 A1 與 PQ／CE／A3a 共用的那個方向，不是 A1 專有的漏洞。

**關鍵數據與例子**

MusicCaps Part B 1,000 prompt、25 步、CFG0、三訓練 seed 平均，對同 seed control 配對（control：A1 2.96／A3a 3.02／PQ 6.67／CE 5.91／CLAP 0.198／FAD 4.21）。m_A1 0.055；轉移比 T＝（Δ指標／該指標系統間全距）÷（ΔA1／S_A1）。

- **量表內推高成立**：主劑量三 seed +0.228／+0.233／+0.233（CI 0.223–0.240），九成 prompt 上升，全體最高 4.49、p95 3.94；160 步的最高也只有 4.84。λ=0 的同步數微調 A1 不動（−0.008），所以增益來自獎勵本身；扣掉對照後 160 步的淨效果是 A1 +0.47、PQ +0.45、CE +0.69。
- **不是 A1 專有、也不隱蔽**：主劑量的 PQ／CE 都超出平手帶（0.10 × 系統間全距），CLAP 沒有下降反而微升，靜音段 28 → 20。唯一朝反方向走的是 FAD，主劑量 +0.12 還在容忍 0.30 內，160 步 +0.59 已超出。
- **轉移比隨劑量緩降**（PQ 0.66 → 0.44、A3a 0.65 → 0.54）：A1 專有的成分隨劑量增加，但到 A3a 轉移比跌破 0.5 之前，分數已經逼近量表上限（完整劑量 3000 步在 Jamendo val 是 A1 10.9、所有 prompt 收斂成同一個聲音）。這條階梯裡沒有「量表內又專攻 A1」的劑量。
- Jamendo val（1-NFE）上的 ΔA1 是 MusicCaps（25 步）上的 1.9～3.9 倍（主劑量 2.6 倍），劑量越大落差越大；兩邊生成路徑不同，只報比值。

**要你決定的事**

1. **（建議）收線，不當攻擊結果。** 論文裡可以寫成一句對照：「直接對 A1 微調，小劑量時 A1／A3a／PQ／CE 一起上升，只有 FAD 不跟」，與 181（PQ 導向訓練推高 MuQ）互為正反兩面，說明 A1 與 PQ 高度共軸。攻擊主線留給教授要的簡單後製手法（低通、188 的疊加固定聲音）。
2. 補 160～600 步的中段劑量，找 A3a 轉移比 < 0.5 而平均 A1 仍 ≤ 5 的點。從趨勢外推，A3a 的轉移比每倍劑量只降約 0.03，量表內大概到不了 0.5；約 4–5 h GPU，不建議。
3. 主劑量與 control 做盲聽（20–30 prompt），判斷這個「一起上升」是真的變好還是幾個指標共同的偏好。這是唯一能把 `general_shift` 往「變好」或「共同偏誤」任一邊推的做法，要聽者。

不可寫：沒有人類評分，不能寫「MuQ 獎勵了較差的音訊」或「聽不出差別」，也不能寫「A1 獎勵微調讓音質變好」；平手帶是 0.10 × 系統間全距，不是 JND；夾在 1–5 是事後處理，不是 MuQ 的定義；主劑量以外的劑量只當描述曲線；只限 MeanAudio 自身、MusicCaps 1,000 prompt、quarter control。
