# MEva fixed-checkpoint audit, 2026-10-03

The user questioned the PAM result and whether AES scores were inflated. Original experiment outputs remain unchanged. This is an audit of `pooled/small/f03_sae_only_cnn_clean_best.pth`, not all MEva variants or a full paper replication.

All 500 PAM table rows were independently joined to original `human_eval/music/scores.csv` by system + filename. OVL labels matched exactly. AES columns matched raw model scores, not Meta human PQ/CE annotations. The generated-only set is exactly 400 clips, four systems × 100 shared prompts. Recalculated Spearman/Pearson and 575 non-tied same-prompt comparisons reproduce prior results exactly.

Fresh GPU inference rescored all 500 clips. All MEva outputs were bit-identical to cached scores. Official upstream `_extract_batch` plus original CNN was independently called for one clip per system (including real); differences from adapter were zero for all five. These checks validate the adapter relative to the pinned code and environment, not historical hardware equivalence or every checkpoint.

Fresh AES produced maximum per-clip changes of 0.00350 PQ / 0.00251 CE from rounded cached values with a different batching context; aggregate correlations were unchanged at displayed precision. On all 500 clips, Pearson was PQ 0.46356 / CE 0.52822, matching AES paper Table 4 rounded values 0.464 / 0.528. On 400 generated clips, Pearson is PQ 0.46033 / CE 0.56880. The two populations must not be conflated.

A diagnostic positive control used 100 random MusicEval clips with native duration ≤30 s, seed 20261003, original OVL range 1.6–5.0. The same MEva checkpoint gave Pearson 0.85021 / Spearman 0.84046. This is not the official held-out test split; sample labels/audio may overlap checkpoint training. It supports a functioning signal path in a familiar domain but cannot independently establish generalization or replicate the paper's test metric.

Paper Table 1 reports SINGLE-SAE small on MusicEval r=0.79, rho=0.80, with supervised per-benchmark held-out splits. This is a correlation coefficient, not 80% pairwise accuracy. PAM is not among its five training/evaluation benchmarks. Our original fixed pooled checkpoint evaluation is zero-shot on PAM; trained benchmark results and external-domain transfer answer different questions. The paper's musicality target, model scope, and audio lengths differ from PAM OVL/5-second generated excerpts. These are plausible transfer explanations, not demonstrated causal mechanisms.

The system-level average MEva ranking also differs from PAM OVL: MusicLDM mean MEva 2.7063 vs MusicGen-large 2.4449, while human OVL is 2.0588 vs 3.0814. This contributes to low aggregate correlation. Within-system correlations remain modest (0.05–0.24).

Correct conclusion: this fixed checkpoint fails the preregistered PAM external validity gate. Do not claim that PAM's 2024 paper evaluated MEva (2026), that MEva is globally random, or that all MEva checkpoints have been disproven. Retain AES and the original MEva shadow scores; a full official held-out replication and independent PromptCC blind evaluation remain necessary before replacement.
