## 判讀（照預先登記的規則）

1. **主端點（primary = S2 快照）**：s2_110k / s2_130k 在所有 w 上 lvl30 dPQ 的 CI 跨 0 或 ≤ 0 → 「在這個設定下沒幫助」。不可寫成「autoguidance 在音訊無效」（只試了同尺寸、訓練較短這一個維度，且 S2 快照與 final 只差 20k–40k iter）。
2. **s2_110k 的高 w 是響度效應**：LUFS +0.85～+2.12、crest −1.26～−1.81，未對齊 PQ 比 lvl30 更差；同 prenorm 延伸看到的「外插放大範數→削平波形」形狀。
3. **探索格（S1 30k）有小而穩的正 PQ**（3 seed、全量都 CI > 0，raw 與 lvl30 同號 → 不是響度），但只有文字負向增益的 7%，且 PC 固定掉 −0.21～−0.24、w 越大 CE／PC／CLAP 掉越多。S1 快照預測瞬時速度，A−A_bad 帶著目標差，**只能寫成「換目標的舊模型當負向分支」的效果，不是 autoguidance**。
4. **不可疊加**：combo 在 3 個 seed 上都讓 CFG3+neg 的 PQ 變差 0.05–0.07，CLAP 平手。文字負向 prompt 已經吃掉的方向，模型式負向分支再推只會扣分。
5. **推力大小仍不解釋增益**：S1 30k 的 ‖A−A_bad‖/‖A‖ 最大（0.20），s2_110k 次之（0.16–0.18）但 PQ 是負的——與 075 分支幾何 probe 的結論一致：負向分支「推多遠」不是關鍵，推的方向才是。
6. **對 negprompt 機制的意義**：「負向分支只要提供一個較差的同類預測就夠」這個說法在這裡不成立——同文字、較差模型給不出文字 fidelity8 的 1/10 增益。fidelity8 的效果仍需要負向槽裡那段**文字**。

## 限制

- 單一語料、單一 checkpoint 家族、單一生成 seed；pilot 選格只在一個 seed 上做（選格偏差會讓 Stage B/C 略偏樂觀，這裡結果本來就小，不影響結論）。
- Karras 原版的 bad model 是「更小且更短」；這裡只有「更短」且差距很近。沒有測小模型當 bad。
- 靜音在 pilot 14 格全部高於 stock，高 w 常破 2×；AG 在這裡一律增加靜音 clip。

## 狀態

收線。不排後續；若要重啟，唯一值得的變體是「更小的 bad model」（需要另訓一個小 S2），且要先有理由相信它能超過文字負向增益的一個數量級以內。
