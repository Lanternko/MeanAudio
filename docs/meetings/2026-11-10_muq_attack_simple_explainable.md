# 2026-11-10 會議：MuQ 攻擊要簡單、可解釋

## 教授的方向

1. **後製攻擊最有力**：模型不動，生成完只做一件小事（例如事後 6 kHz 低通），分數就上去，而人類不覺得變好——這是最直接的證據。訓練期針對性 optimize（081／084、L 臂低通語料重訓 S2）也可以，但比較間接、說服力較弱。
2. **要在能聽的音檔上證明**：CFG0（PQ 6.67）太難聽，L 臂要報 CFG3。「好音檔被壓掉高頻、分數反而升」比「兩個爛音檔比高低」有說服力。CFG3 上 L 臂只 +0.026，但不代表不顯著。
3. **可以往下壓**：6 kHz 有效，就試 5k／4k／2k，或某頻段 +10 dB、另一頻段 −10 dB 這類簡單 EQ。
4. **R 臂（A1 獎勵微調）分數 10.93 本身沒意義**（reward hacking 對任何模型都刷得上去），但要**聽它生成了什麼、解釋它做了什麼**：是不是某個頻帶、某個固定節奏（例如每 0.1 秒一下）、某種特定聲音（會議中聽起來像喇叭聲）。解釋出來就知道 MuQ 的弱點。
5. **越簡單、越描述得出來越好**：例如「疊一個 1 kHz 正弦波」「疊一段咚咚咚的簡單伴奏」「加 high pass」。要能用一句話講清楚，不靠聽音檔。理由：描述得出來的捷徑，研究者靠反覆跑實驗、挑 MuQ 最高的那組（不給梯度），就可能不經意地讓生成模型學到。
6. 同樣的思路也可以拿去打 PQ 等其他指標，目的是說服讀者這些指標不可靠。
7. 實驗室第三台 5090 這幾天沒人用，可以用。
